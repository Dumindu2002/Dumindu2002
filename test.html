📖 Setup Instructions

Option 1: Direct Browser Access (No Server Required)

  1. Open index.html directly in your browser
  2. All features work except real payment processing
  3. Perfect for demo and testing purposes

Option 2: With Node.js Server (Full Features)

  1. Run: npm install
  2. Run: npm start
  3. Visit: http://localhost:3000
  4. Configure Stripe keys for real payments
